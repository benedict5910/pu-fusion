## 3. OB2 – corrected sensor-quality detector (`src/pufusion/reliability_v2.py`)

**Diagnosis.** The original detector learns one range per indicator from all training bearings and
conditions pooled (+25 % margin). Inner leave-one-*training*-bearing-out showed that *every* tighter
absolute model (per-condition boxes, robust Mahalanobis) false-flags 10–23 % of clean windows on an
unseen bearing: clean indicators differ between individual bearings about as much as noise or gain
errors shift them. Absolute label-free ranges cannot separate them.

**Correction.** Commissioning-baseline variants: each sensor's indicators are compared with the
median of its own first clean recording (repetition 1) under the same operating condition; the
allowed deviation (box or robust Mahalanobis) is learned from training bearings only. No fault
labels are used. **Assumption:** a known-good baseline is recorded when a sensor is installed.

**Protocol.** Per fold, the configuration is chosen from a fixed candidate list (6 absolute + 4
baseline) by inner leave-one-training-bearing-out, using clean false flags (≤ 5 %) and detection of
seen families only (noise, dropout, intermittent, gain). Test bearings and the withheld families
(clipping, spikes, stuck) are never used. Selected: box-baseline in 9/15 folds, Mahalanobis-baseline
in 6/15. Evaluation on repetitions ≥ 2 of held-out bearings (`results/ob2_v2/quality_v2.json`).

| Held-out detection (15 folds) | v1 vib | **v2 vib** | v1 cur | **v2 cur** |
|---|---|---|---|---|
| Clean false flags (all / healthy / damaged bearings) | 1.5 / 0.0 / 2.2 % | **5.6 / 0.9 / 7.8 %** | 1.3 % | **1.7 %** |
| Gain ×0.5 / ×2.0 | 2 / 16 % | **90 / 100 %** | 8 / 76 % | **100 / 100 %** |
| Noise −5 / 0 / 5 / 10 / 20 dB | 16 / 8 / 4 / 2 / 1 % | **100 / 100 / 87 / 46 / 4 %** | 100 % | 100 % |
| Spikes 10 / 100 / 1000 per s (**withheld**) | 2 / 3 / 11 % | **26 / 65 / 100 %** | 100 % | 100 % |
| Clipping, stuck, dropout, intermittent | 97–100 % | 97–100 % | 100 % | 100 % |

Cost: more clean false flags on vibration, mainly on damaged bearings (7.8 %), where the signature
changes between recordings. Mild noise (20 dB) is still not detected.

## 4. OB1 / OB2 – fusion comparison (`results/ob_final/`)

P1, 11 bearing-disjoint runs, 12-bearing starter subset, held-out bearings, repetitions ≥ 2.
`gated_v2` = learned gate + exclusion rule fixed **before** evaluation: a sensor flagged by the v2
detector gets weight 0; both flagged → abstain. Macro-F1 counts an abstained window as wrong.

| Model | Clean F1 | Seen-corr. F1 | Withheld F1 | Coverage (seen / withheld) | FAR (clean) | Missed faults (clean) |
|---|---|---|---|---|---|---|
| vib_only | 0.562 ± 0.185 | 0.520 | **0.469** | 1 / 1 | 0.443 | 0.132 |
| cur_only | 0.322 ± 0.137 | 0.304 | 0.268 | 1 / 1 | 0.598 | 0.323 |
| early_fusion | **0.567** ± 0.162 | **0.535** | 0.406 | 1 / 1 | 0.446 | **0.075** |
| late_average | 0.558 ± 0.166 | 0.524 | 0.398 | 1 / 1 | 0.443 | 0.135 |
| late_stacked | 0.388 ± 0.050 | 0.373 | 0.294 | 1 / 1 | 0.632 | 0.301 |
| gated_both (original) | 0.533 ± 0.173 | 0.508 | 0.455 | 1 / 1 | 0.471 | 0.141 |
| gated_v2 | 0.521 ± 0.154 | 0.429 | 0.451 | 0.906 / 0.962 | 0.472 | 0.139 |

Statistics (Holm-corrected paired Wilcoxon, run-level and bearing-level, n = 11 runs / 12 bearings):
no gated model is significantly better than vibration-only, early or average fusion in any group.
`gated_v2` is significantly better than current-only and stacked fusion under withheld corruptions
(run-level), and significantly *worse* than early fusion under seen corruptions (bearing-level,
p_holm = 0.018).

**Interpretation.** Better detection did not give better diagnosis. When vibration is mildly noisy or
mis-gained the vibration expert is still informative (vib_only 0.56 under gain errors), so excluding
it in favour of the weak current expert (≈ 0.32) loses accuracy, and abstaining on dual noise lowers
coverage. The original learned gate (`gated_both`) remains the better diagnostic model. Because this
was seen on test data, no new fusion rule was tuned here; choosing an exclusion/down-weighting policy
by inner cross-validation on training bearings is listed as future work.

Per-class (clean, pooled): healthy recall 0.54–0.58 for all fusion models; outer race is the hardest
class (F1 0.44–0.48). Bearing-level accuracy is dominated by two healthy bearings (K002 ≈ 0.24,
K004 ≈ 0.15–0.18) – the known false-alarm issue – and by KI14 / KA04. Confusion matrices:
`results/ob_final/confusion_clean.png`, `confusion_withheld.png`; full tables in
`ob_final_results.json`.
